VitalStream build workflow

How the manager agent and worker agents build this repository. Status pills are updated by the manager on every merge.

Loop per workstream

Manager writes contract + task
→
Worker branches
→
Failing test
→
Code to green
→
Refactor, docs, logs
→
Run for real
→
PR + CI
→
Manager review
→
Merge or send back

Phases

Phase 0 – Manager. Tooling (Java 21, Maven, kubectl, kind, Helm, Terraform, Colima 6 CPU / 16 GB), repo, README, CONTRIBUTING, CONTRACTS, this board.
Wave 1 – parallel. Foundation, ingest-gateway, stream-processor, clinical-api, copilot. Each codes against CONTRACTS.md and tests with Testcontainers, so none waits on another.
Wave 2 – parallel. Simulator + dashboard (needs live APIs for visual checks), Kubernetes + Helm + Terraform, CI/CD + end-to-end + n8n.
Wave 3 – Manager. Full-stack run, screenshots into docs/images/, architecture & interview guide.
